# The Mini Solar System
This project is made to practice my three.js skills, and it is simply a mini solar system that contains:
- The Sun
- The Earth
- The Moon
- A random probe
- Saturn and its rings
and all of these are rotating around themselves, and they orbit around the sun.



## Why did I make this project ? 
I made this project to practice my skills in three.js to create 3d websites.
